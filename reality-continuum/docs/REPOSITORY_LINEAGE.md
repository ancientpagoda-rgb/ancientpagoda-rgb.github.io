# Repository Lineage

Reality Continuum is a new project, but every repository discovered in `ancientpagoda-rgb` contributes a design lesson or subsystem.

| Repository | Contribution to Reality Continuum |
|---|---|
| `reality-sandbox` | Broad simulation ambition, deterministic systems, abiogenesis experiments, staged social emergence, browser validation culture. |
| `ancientpagoda-rgb.github.io` | Public portal/deployment hub and proof that multiple experiences can share one web presence. |
| `reality-engine` | Shared world-state abstraction, regime detection, real-data inputs, visuals + audio driven by one state. |
| `planetary-signal` | Sonification of space weather, terrestrial weather and human systems. |
| `world` | Live Earth globe, weather/data pipelines, country views, IPA/language layers, refresh workflows and browser smoke tests. |
| `backup-hardening-landing` | Productization and operational hardening as an explicit user-facing concern. |
| `borg-backup-kit` | Encrypted automated backups, retention and restore drills for persistent worlds/data. |
| `universe` | Large astronomical catalog point clouds and a persistent desktop-scale universe view. |
| `predictorjesus-site` | Forecast/prediction-product lineage; folded into a general forecasting/uncertainty interface rather than a separate theme. Repository contents were not accessible to the integration during this synthesis. |
| `extinct` | Legacy/empty experiment becomes part of the project’s “fossil record”: retired ideas are preserved, not silently erased. |
| `cosmic-clock` | Real astronomy, Sun direction, ephemerides, scale transitions and cosmic-time UI. |
| `virtual-plant` | Plant-scale growth and garden interaction as a micro-ecology lens. |
| `world-at-a-glance` | Country-level indicators, choropleths and scheduled data refresh. |
| `universe-dashboard` | Daily astronomy/space-data dashboard patterns. |
| `reality-forest-3d` | Forest-scale 3D world lineage and the importance of a local ecological scale between organism and planet. |
| `mow-the-planet` | Touch-first spherical world, autonomous workers, predators, resource regeneration, adaptive rendering and playful embodied interaction. |
| `-` | Empty/placeholder lineage; represented as the experimental scratch-space concept rather than copied code. |
| `brain-wiring-atlas` | Brain anatomy/wiring reference lens and heavy browser-ready scientific data packs. |
| `reality-sandbox-extinct` | Archived simulation lineage; informs explicit version retirement and fossilized experiment access. |
| `marchwarden` | Persistent settlements, embodied hero + strategy view, resources, raids, construction, WebSocket/shared-state architecture. |
| `earth-in-universe` | Continuous conceptual zoom from Earth outward to Solar System, Milky Way and observable universe. |
| `world-timeline-sim` | Historical anchors, language/population change, timeline scrubbing and explicit uncertainty. |
| `cosmic-ecology-sandbox` | One authoritative clock, procedural living planet, hydrology, ecology, evolution, inspector coupling and strong scientific boundary labeling. |
| `earth-777` | Scientific provenance, paleo reconstruction, checksum-pinned data ingestion, uncertainty classes, hydrology/ecology rigor and Free Earth branching. |
| `epic-evolution-sim` | The deepest continuity rule: cosmos → galaxy → star → planet → chemistry → Darwinian life, with inherited state across scales and GPU-oriented rendering. |

## Synthesis rule

No old project is embedded wholesale merely to claim coverage. Its strongest idea is re-expressed through a shared state model, provenance contract, rendering interface and scale/time navigation system.
